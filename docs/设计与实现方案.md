# 频域定向向量扰动：设计与实现方案

版本：设计稿 1.1；日期：2026-09-09；状态：设计已实现，正式实验待验证。

> 实现说明：本文第三至第五节对应的固定频带、公平像素基线、公共缓存、逐代理梯度、分阶段评估、计时、显存和汇总代码已经完成。真实单样本一步链路已贯通，但 25 步及 1000 步正式实验尚未运行。实际命令和核查证据见《实现与运行说明》和《实现核查记录》；本文保留设计时的研究假设与边界，不把实现完成写成效果成立。

## 1. 任务结论与范围

公子，技术上可行：把“需要优化的变量”由逐像素扰动换成频率系数，经过可微的逆变换恢复成像素，再让模型计算向量和梯度。整个过程能够反向传播，不需要额外训练生成模型。

但可行不等于一定优于像素方法。限制频率可能过滤掉无效方向，也可能限制最优解；变换本身还增加计算。我们检验的是“是否在本项目的数据、模型、约束和设备上有更好的效果—成本折中”，不预先承诺结果。

研究对象是本地、受控的图像向量实验。向量更接近目标图，不自动意味着智能体会记错、检索会改变排名或最终回答会出错。本阶段不作这些扩大结论，也不复现原论文的全部实验。

本文件中的新方法和阈值是预先制定的设计；方法已经编码，阈值仍不是已验证结果。旧项目事实与实现风险见《现有项目兼容清单》。

## 2. 到底修改什么

### 2.1 原方法

设源图为 \(x\)，每个颜色通道的数值归一化到 \([0,1]\)。原方法直接保存一个与图片一样大的扰动数组 \(\delta\)，根据目标函数的梯度符号更新，再限制每个像素最多改变 \(16/255\)。

例如，一个红色通道像素原来是 120，某一步可能变成 120.5；最后保存图片时再取整。所有位置都可以有各自的变化量。

### 2.2 本方案

使用 DCT（离散余弦变换）的正交第二型基底，保存系数数组 \(A\)。每个系数控制一种固定的二维明暗变化模式：低频变化宽、缓；高频变化窄、密。系数决定变化的正负和强度。

举例：某个系数增大，会使图片左侧一些位置同时变亮、右侧一些位置同时变暗；另一个系数控制纵向变化。实际二维模式通常不是简单的一分为二，而是连续余弦变化。算法每步一起调整许多系数。

**不用先改目标图，也不用直接篡改模型输出的向量。我们修改源图的频率扰动系数，模型看到的是恢复并保存后的普通图片。**

使用单独的“扰动系数”，而不是覆盖源图的频率系数，便于明确控制扰动大小。在线性变换且没有裁剪时，两者可以相互转换；这里选择前者是工程表达方式，不是额外创新。

### 2.3 一个完整的更新过程

```text
源图 + 当前频率系数合成的扰动
            ↓
限制图片合法范围，送入原来的三个代理编码器
            ↓
计算与目标图、目标文本及局部特征的接近程度
            ↓
反向求导：哪些频率系数应增加，哪些应减少
            ↓
更新系数，并把合成扰动限制在同样的像素预算内
            ↓
重复；最后保存图片，再用原来的评估器重新编码
```

## 3. 数学定义：足以直接实现的版本

### 3.1 输入与归一化

- 源图 \(x\in[0,1]^{1\times3\times H\times W}\)，保持源文件解码后的原始高宽。
- 目标图 \(t\) 可以有不同高宽；由同一代理编码器的原有预处理完成尺寸变换。
- 图片统一为 RGB（红绿蓝三通道），不自行添加方向校正、中心裁剪或新的缩放逻辑。
- \(f_m\) 为第 \(m\) 个冻结参数的代理编码器，\(m\in\{1,2,3\}\)。图像全局向量和文本向量均按原实现归一化。
- 总扰动上限 \(\epsilon=16/255\)，名义空间步长 \(\alpha=0.5/255\)。这里“空间步长”是合成到像素后的最大变化幅度，不是直接给频率系数套用像素单位。

### 3.2 紧凑频率参数化

对高度方向定义正交矩阵：

\[
C_H[k,n]=\beta_k\cos\left(\frac{\pi(2n+1)k}{2H}\right),\qquad
\beta_0=1/\sqrt H,\quad\beta_{k>0}=\sqrt{2/H}.
\]

宽度方向同理。取最低的 \(K_H\) 与 \(K_W\) 个频率，令 \(B_H=C_H[0:K_H,:]^T\)、\(B_W=C_W[0:K_W,:]^T\)。每个颜色通道分别合成：

\[
\delta(A)=B_H A B_W^T.
\]

因此只需要优化 \(3K_HK_W\) 个系数。缺省设计为 \(K_H=\lceil H/4\rceil\)、\(K_W=\lceil W/4\rceil\)，也就是每个方向保留四分之一，而不是保留四分之一的全部系数；高宽能整除时，系数数量约为全图的十六分之一。

预试只比较方向比例 \(1/8,1/4,1/2\)，不做大范围搜索。常数项默认保留；是否去除整体颜色偏移仅作以后单独消融。首先固定频带，不同时引入自适应频带、多种优化器和新损失。

变换采用正交归一化，正反变换必须使用相同约定；数学核对参考 [SciPy（科学计算库）的变换说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.fft.dct.html)。训练路径用 PyTorch（张量计算与自动求导框架）实现，不能转成不保留计算图的数组后再求梯度。该数学来源不意味着需要在每步调用该科学计算库。

### 3.3 原目标函数保持不变

为隔离“换成频域”的影响，首轮不改原项目的损失：

\[
J=\sum_{m=1}^3 w_m s_m^{global}
 +0.2\frac{1}{3}\sum_{m=1}^3 s_m^{local}
 +1.0s^{text}.
\]

- \(s_m^{global}\)：当前图与目标图的全局向量余弦相似度。
- \(s_m^{local}\)：各自局部图块特征聚成十个中心，再通过 OT（最优传输）计算匹配相似度。沿用原来的聚类与传输迭代设置。
- \(s^{text}\)：第二个代理编码器的图像向量与目标文本向量相似度。
- 初始权重 \(w_m=1/3\)，一步结束后按当前步更新前的全局相似度计算 \(w_m\propto\exp(-s_m^{global})\)，用于下一步。
- 优化方向是最大化 \(J\)，所以沿正梯度更新；不能把最小化损失的符号直接照搬。

这个目标与“只追目标图向量”不完全相同，文本和局部项可能发生方向冲突。但先保留它才能公平比较。若主实验发现目标图增益停滞，再在像素组与频域组同时比较文本权重为零的版本，不能只为频域组换更有利的损失。

### 3.4 频率系数怎样更新

从 \(A_0=0\) 开始。第 \(k\) 步：

1. 合成 \(\delta_k=\delta(A_k)\)，得到 \(x'_k=\operatorname{clip}_{[0,1]}(x+\delta_k)\)。
2. 计算 \(J(x'_k)\)，自动求导得到 \(g_k=\nabla_{A_k}J\)。
3. 取系数更新方向 \(U_k=\operatorname{sign}(g_k)\)，合成它的空间方向 \(D_k=B_HU_kB_W^T\)。
4. 用空间幅度校准步长，而不是直接比较两种参数化的系数数值：

\[
\widetilde A_{k+1}=A_k+
\frac{\alpha}{\max(\|D_k\|_\infty,10^{-12})}U_k.
\]

5. 合成 \(\widetilde\delta=\delta(\widetilde A_{k+1})\)。若它超过像素扰动预算，则在空间预算盒和低频子空间之间执行有限轮交替投影：

\[
\delta^{(t)}_{clip}=\operatorname{clip}(\delta(A^{(t)}),-\epsilon,\epsilon),
\qquad
A^{(t+1)}=B_H^T\delta^{(t)}_{clip}B_W.
\]

正交重投影可能再次产生少量超限，因此首版默认执行一轮并立即重新检查。该轮结束后若仍超限，再执行一次整体缩放兜底；配置允许后续在单独实验中增加重投影轮数：

\[
\rho=\min\left(1,\frac{\epsilon}{\max(\|\delta(A^{(T)})\|_\infty,10^{-12})}\right),
\quad A_{k+1}=\rho A^{(T)}.
\]

6. 更新代理权重，记录空间截断比例、重投影轮数、兜底缩放和必要统计，再进入下一步。若梯度全零，记录此状态，不能除零或静默宣称收敛。

第五步不是对两个约束交集的一步精确欧氏投影。空间截断只在当下改变超限位置，但随后的低频正交投影是全局操作：它可能改变原本未超限的位置，也不能保证一次投影后仍满足像素预算。最终兜底负责严格可行性；交替投影是否比直接整体缩放保留更多有效扰动以及额外耗时多少，必须通过统计和对照实验判断，不能预先保证。

### 3.5 为什么有梯度

在图像合法范围裁剪之外，合成是线性操作。若图像空间的梯度为 \(G\)，那么每个通道的系数梯度为：

\[
\nabla_AJ=B_H^TGB_W.
\]

实际 \(G\) 要包括合法范围裁剪的导数；饱和位置的梯度可能为零。用自动求导处理它，不能假装裁剪从未发生。

所有频率都保留时，变换本身只是可逆的坐标变化。但“在系数上取符号”和“在像素上取符号”，以及整体缩放和逐像素裁剪，通常会产生不同迭代轨迹。全频版本只用于对照，不应被写成像素版本的完全同义实现。

### 3.6 最终保存与频带泄漏

最终浮点图片为 \(x'=\operatorname{clip}_{[0,1]}(x+\delta(A))\)，然后乘 255、四舍五入、转八位整数并保存 PNG（无损图片格式），与原项目一致。由于源图是八位整数解码，且预算是整数十六个灰度等级，正确实现应满足解码后逐通道最大差不超过 16；必须实际检查。

重投影及兜底后的原始 \(\delta(A)\) 限频，不代表落盘图片的差值严格限频。范围裁剪和整数取整会产生额外频率。输出中分别测量：合成前约束后的原始扰动、合法范围裁剪后的实际扰动、重新读取图片后的扰动。

频带外能量比例定义为：

\[
r_{out}=\frac{\|(1-M)\odot\operatorname{DCT}(x'-x)\|_2^2}
{\|\operatorname{DCT}(x'-x)\|_2^2+10^{-12}}.
\]

\(M\) 是选定频率位置的二值掩码。应同时记录范围裁剪的像素比例。本文主方法准确名称为“频域参数化的扰动”，不把最终图片宣传为严格低频图片。

## 4. 省时、省显存的设计：分清归因

### 4.1 同时给像素和频域版本的公共工程优化

| 优化 | 代码依据与做法 | 公平性要求 |
|---|---|---|
| 缓存目标局部聚类中心 | 目标图特征已缓存，但原局部相似度函数每步重新聚类目标特征；聚类初始化由固定位置决定 | 两组都缓存；先验证中心、损失和梯度一致 |
| 每个实验进程只加载一次三个代理 | 原流程每个样本重新进入模型加载 | 两组使用同一生命周期；分别报告冷启动和热运行 |
| 逐代理反向传播累积梯度 | 原代码一次保留三套图像计算图；分别计算每个代理对同一扰动状态的梯度，再相加 | 一步中不更新扰动、不提前更新权重；等所有代理贡献齐全后统一更新 |
| 选择、攻击、评估分阶段 | 先冻结选图清单，再释放选择模型；生成阶段不常驻额外评估器 | 两组相同；评估模型及预处理不变 |
| 公共候选与目标特征缓存 | 缓存键含图片内容、完整文本、权重版本、预处理和精度 | 只复用确定性的中间结果，不复用某组的最终攻击图 |

逐代理反向传播时，可把当前合成图做成需要梯度的叶子，各代理依次计算对该图的梯度并累计；最后通过一次合成计算图传回系数。这样不必保留三套视觉主干的反向图。测试必须证明与同时计算的梯度在容差内一致。三个代理的参数仍可常驻显存，因此减少激活峰值不等于模型权重显存也减少。

保留原始三十二位攻击精度；混合精度是后续两组共同的可选实验，不能只给一组使用。原代码在传输迭代停止条件和每步统计上包含设备到主机同步；改变停止判据可能改变算法，暂不改。减少不必要日志同步也必须对两组同步实施，保留原有日志频率对照。

### 4.2 频域方法自己的低成本设计

1. **紧凑系数与基底缓存。** 仅存选定频率系数，按图片高宽和精度缓存基底。不要一开始就创建全尺寸正方形变换矩阵。紧凑矩阵乘法也可能比快速变换慢，应记录变换时间和缓存大小。
2. **先固定频带，必要时渐进扩频。** 只有固定频带小实验有潜力才比较扩频：已消耗优化预算的 0%—30% 用八分之一方向比例，30%—70% 用四分之一，之后用二分之一。切换时旧系数原样嵌入，新频率初始化为零，不重启扰动。固定与扩频使用相同总时间预算。
3. **按空间幅度校准更新。** 避免频率系数的归一化尺度导致某组实际走得更大，从而产生虚假提升。

扩频比例和切换时刻只是预先提出的候选，不是证明最优的设置。扩频有利与否必须比较曲线，不能只挑最好的最终图片。

### 4.3 暂时不做的事情

- 不默认加入扩散生成、额外大模型、可学习图像生成网络或多卡训练。
- 不把代理从三个减成一个作为主频域方法的优势；若后续试验，像素与频域都减少，并明确改变设置。
- 不降低图像原始分辨率、扰动上限或更换选图后，仍称为原实验的同条件胜出。
- 不把“频率系数少十六倍”写成“训练快十六倍”。视觉编码器的前向、反向可能仍占主要时间。
- 不在正式测试集上不断改频带、损失或停止条件。

## 6. 开发顺序与单元测试

### 阶段一：冻结与兼容

已经生成历史十组清单与参考源码指纹，并在真实模型核查中记录三个代理及主评估器的本地权重修订、内容摘要和预处理。选图重算已覆盖 217 个候选和 35 个查询，冻结前十行逐行匹配 10/10；该核查不生成对抗图片。若将来数据、权重、版本或预处理变化导致不一致，应先定位差异，不能静默替换历史目标。

### 阶段二：公平像素基线

参考像素与公平像素更新、计时、峰值显存和最终重算已经实现。单元测试证明逐代理梯度与联合梯度在预定容差内一致；真实首步的两种像素方法目标值和落盘图片完全一致。短程及 1000 步差异仍待实验。由于浮点顺序变化，长程位级相同不是合理保证；要保存差异和容差。

### 阶段三：固定频域

本文件第三节的固定频带版本已经实现，未加入新损失；渐进扩频作为默认关闭的独立候选。当前自动测试包含：

- 正交基底、完整正反变换重建、能量守恒；小矩阵双精度误差目标不超过 \(10^{-10}\)。
- 奇数高宽、长方形图片、三通道与批大小一；完整与紧凑合成一致。
- 非饱和位置有限差分检验系数梯度，建议相对误差 \(10^{-4}\)；饱和点单独测试，不在不可导边界作错误断言。
- 零系数还原源图、零梯度不产生非法数值、每步合成扰动不超过预算加 \(10^{-6}\) 容差。
- 图片保存再读取后最大整数差不超过 16，尺寸和通道不变。
- 最后一步更新后重新计算损失；日志不能把更新前指标标成最终图片指标。
- 同一图片、文本、权重、精度命中缓存；任何一个变化必须失效。
- 公共逐代理梯度与共同计算梯度的单步对照；先建议相对误差 \(10^{-4}\)，若不满足先查原因，不直接放宽。
- 原字段输出一致，重复源图仍按十个问题行保留，失败样本不从分母删除。
- 评估器不可反向参与优化，正式测试没有动态查看目标评估器成绩来调参。

### 阶段四：小实验与停止判断

同一个冻结样本上的公平像素与固定频带一步冒烟已经验证整条数据链；它只用于实现核查。按本轮“一组即可测试”的范围，没有继续运行 25 步或多组长实验。若以后决定继续研究，仍应先做短程验证，再把历史样本用作兼容和探索集合，限制参数候选与试跑预算；确有收益再冻结设置进入同规则的新样本测试。实验分组、计时及判定见独立协议。

## 7. 论文价值的边界

频率基底和基底方向搜索并非从零开始的新思想；已有基底方向攻击研究，例如 [Simple Black-box Adversarial Attacks（简单黑盒对抗攻击）](https://proceedings.mlr.press/v97/guo19a.html)。该来源用于提醒“更换搜索坐标并不自动构成创新”，不是本方案在多模态记忆任务上的有效性证据。本文不是该论文的阅读报告，也未在本次核验任何投稿级别。

本项目可能值得继续研究的证据是：在固定图像对、实际保存的图片和同一模型下，证明频带结构或渐进策略能稳定改善向量接近程度与计算成本的折中；再解释这种改善出现在哪些图像和方向上。缓存优化本身应报告为工程贡献。

只有十组历史样本、只有一个与代理重合的评估模型，不足以声称具有普遍迁移性或已经具备发表条件。若小实验无收益，应保留负结果，不能靠增大扰动、换容易的图或隐去失败样本维持结论。
